# 🎂 Birthday Gift - "From India with ❤️"

> *"Some stories aren't written..... they're lived."*

A cinematic, interactive birthday gift for someone special.  
Built with pure **HTML, CSS, and JavaScript** — no frameworks needed!

---

## ✨ Features

- 🎬 **9 Cinematic Scenes** with smooth auto-transitions
- 🌍 **India ↔ Indonesia** map animations
- 💬 **Chat bubbles** with typing effect
- 🎮 **Roblox & Discord** themed scenes
- ❤️ **Curved line animation** connecting two hearts
- 📸 **Photo gallery** with pop-in effects
- 🎊 **Confetti burst** on birthday wish
- 🎵 **Sound effects** for every scene
- 📱 **Fully responsive** (mobile friendly)
- 🖱️ **Click or Arrow Right** to skip ahead
